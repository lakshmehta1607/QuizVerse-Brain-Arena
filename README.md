# QuizVerse – Brain Arena

## Python Programming Lab Course End Project

QuizVerse – Brain Arena is a desktop-based quiz application developed using Python and Tkinter.

## Features

- Multiple quiz topics
- Easy, Medium and Hard difficulty levels
- Classic, Blitz, Survival and Streak Rush modes
- XP and level system
- Achievement system
- 50/50 and Skip lifelines
- Timer-based questions
- Persistent player statistics
- Excel-based question bank
- Question explanations

## Technologies Used

- Python
- Tkinter
- JSON
- Excel
- XML parsing
- Python Standard Library

## Requirements

- Python 3.8 or later
- Tkinter
- quizverse_questions.xlsx

## How to Run

Keep `quizverse_ultimate.py` and `quizverse_questions.xlsx` in the same folder.

Run:

```bash
python quizverse_ultimate.py
